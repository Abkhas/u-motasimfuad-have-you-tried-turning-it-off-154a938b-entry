A [make.fun](https://make.fun) one-line entry: a single funny line, under 200 characters, that a hopeless tech support agent says to a desperate customer.

> Have you tried turning it off and on again? I did — the whole call centre. You're talking to the last light still on.

`main.py` writes the line to `/output/entry.txt`.
